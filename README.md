# 皇帝牌

皇帝牌 E-CARD 線上對戰版

這是一個簡單的雙人線上對戰網頁遊戲，使用 PeerJS 直接在瀏覽器兩端建立點對點連線。

## 遊戲玩法

- 一個玩家建立房間，成為「皇帝方」
- 另一個玩家加入房間，成為「奴隸方」
- 每回合各自出一張牌
- 牌型關係：
  - 皇帝 > 奴隸
  - 奴隸 > 市民
  - 市民 > 皇帝
- 若雙方都出同一張牌，則為平手
- 每回合結束後會更新分數，直到牌組耗盡或遊戲結束

## 啟動方式

1. 下載或複製本專案
2. 直接開啟 `index.html`
3. 其中一人點選「建立新房間」
4. 另一人輸入房間代碼後點選「加入房間」
5. 連線成功後即可開始遊戲

## 注意事項

- 這是瀏覽器端點對點遊戲，建議在同一區域網或可互聯網路環境下測試
- 若要正式部署到網站，建議使用 HTTPS
- 若在本機直接開啟檔案時遇到連線問題，請使用本地伺服器方式執行
